## ⚠ Highest-attention items (owner decision required)

**TOP 1 — Report a Bug sends environment data to a public GitHub tracker (entry 1).**
`Header.tsx` `buildBugReportUrl` pre-fills `github.com/Taha-Aalam/Vastukar/issues/new`
with the full user agent, the raw page path **including query string**, UI locale, build
fingerprint, app version, and the last error message + 30 stack lines + error-page URL.
Error text is anonymized by `errorLogger.anonymize`, but UA and route query are NOT
(token-bearing share/portal paths are masked in the logger, not in this Page line).
User-initiated and gated (≥20-char description, network-blip warning), but one click
publishes environment detail to a public issue. Decide channel + payload scope.

**TOP 2 — The self-upgrade flow installs the UPSTREAM package (entries 9, 11, 12).**
`POST /api/system/upgrade` and `openconstructionerp upgrade` run
`pip install --upgrade openconstructionerp` — the upstream PyPI distribution. Applying
it replaces the Vastukar fork with upstream OpenConstructionERP. There is **no signature
or checksum verification beyond pip's own TLS + PyPI hash checking** (contrast: the
converter installer has SHA-256 pins + a signed-manifest flow). The version-check
endpoint likewise compares the fork's version against **upstream PyPI** releases.
Gated: admin role + `ALLOW_RUNTIME_UPGRADE` (off by default) + demo-account refusal +
frozen-build refusal; the Part 1 UI removal left the endpoints dormant but reachable.
Repoint to a fork-owned distribution channel or remove the runtime-upgrade surface.

Also high-attention: the **desktop launcher offers upstream releases as updates** and
send users to upstream support (entries 14, 68); the **ddc-integrity provenance
injection** wired into every page load (entry 45); and the **upstream cost-data
dependencies** — catalogue CSVs + CWICR v3 HuggingFace dataset + converter binaries
(entries 26, 28, 29).
